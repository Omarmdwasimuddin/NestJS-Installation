## NestJS Installation

## Prerequisites
##### Note: Please make sure that Node.js (version >= 20) is installed on your operating system.
#### node & npm version check
```bash
node -v
npm -v
```

#### Installation
##### Installing NestJS CLI
```bash
npm i -g @nestjs/cli
```
##### Creating a New NestJS Project
```bash
nest new project-name
```
